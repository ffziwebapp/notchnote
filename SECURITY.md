# Keamanan NotchNote

## Memeriksa installer

Penjelasan lengkap tentang cara memastikan installer aman (kode terbuka, build otomatis di GitHub Actions, VirusTotal, sidik jari SHA-256, dan data apa saja yang dikirim lewat internet) ada di bagian [Keamanan di README](README.md#keamanan).

Unduh NotchNote **hanya** dari halaman [Releases](../../releases) di repositori ini. File yang dibagikan lewat tempat lain bisa saja sudah diubah orang. Cocokkan dulu sidik jari SHA-256-nya dengan yang tertulis di halaman rilis.

## Versi yang didukung

Perbaikan keamanan hanya dibuat untuk versi terbaru. Perbarui dengan mengunduh installer terbaru lalu memasangnya di atas versi lama. Datamu tidak akan hilang.

## Melaporkan masalah keamanan

Kalau kamu menemukan celah keamanan, atau antivirus menandai installer resmi dari halaman Releases:

1. Buka tab [Issues](../../issues), lalu buat issue baru.
2. Tuliskan versi NotchNote, apa yang terjadi, dan (kalau dari antivirus) nama antivirus serta nama deteksinya.
3. Jangan sertakan API key, kata sandi, atau data pribadi di dalam laporan.
